# Planteamiento del problema

La comunicación es una parte fundamental de la interacción entre las personas. Sin embargo, existen situaciones en las que las diferencias en los medios de comunicación pueden generar dificultades para transmitir información de manera rápida y comprensible.

Entre estas situaciones se encuentra la comunicación mediante la lengua de señas, utilizada principalmente por personas sordas y con discapacidad auditiva.

## Limitaciones de las herramientas actuales

Actualmente existen diferentes herramientas y aplicaciones relacionadas con el aprendizaje o traducción de lengua de señas, pero muchas de ellas presentan las siguientes limitaciones:

- Están enfocadas únicamente en una dirección de comunicación.
- Funcionan como diccionarios visuales.
- Requieren la participación de otra persona que conozca la lengua de señas.

Esto genera la necesidad de desarrollar herramientas tecnológicas que permitan una interacción más directa y accesible.

## Propuesta

A partir de esta necesidad surge la propuesta de desarrollar una aplicación basada en Inteligencia Artificial capaz de trabajar con la Lengua de Señas Mexicana (LSM). El proyecto busca utilizar técnicas de visión artificial y aprendizaje automático para identificar las señas realizadas por una persona mediante una cámara y convertirlas en texto.

Además, el sistema contará con un módulo que permitirá realizar el proceso inverso, donde el usuario podrá introducir texto y recibir una representación visual de las señas correspondientes. De esta manera, se busca establecer un sistema de comunicación bidireccional entre texto y lengua de señas.

Como complemento, se incorporará un módulo educativo orientado al aprendizaje de la lengua de señas. Este permitirá que los usuarios consulten diferentes señas, observen ejemplos de cómo realizarlas y posteriormente practiquen frente a una cámara. El sistema podrá utilizar el modelo de Inteligencia Artificial para reconocer la ejecución realizada y proporcionar una evaluación o retroalimentación básica sobre su desempeño.

## Alcance inicial

El desarrollo inicial se enfocará en un conjunto limitado de señas y palabras, con la posibilidad de ampliar progresivamente el vocabulario y las capacidades del sistema.
